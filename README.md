# 遥感影像智能解译系统 (Remote Sensing AI Land-Cover & Feature Extraction)

本项目针对 **遥感卫星多光谱影像 (如全球30米 SDC30 数据立方体)** 与 **高分辨率航空遥感图**，构建了基于 **多光谱物理反演增强与 YOLO 深度学习** 的遥感地物智能解译平台。原生支持大尺度切片滑窗、空间坐标映射与全要素成果导出。

---

## 🌟 核心特性

1. **水系专属高精度物理反演引擎 (`rs_water_detector.py`)**：
   - 专门针对 **湖泊、水库、河流干流、灌溉渠道、坑塘** 等地表水体地物。
   - 结合多光谱 **MNDWI (改进归一化差异水体指数)**、**NDWI** 与近红外极低反射率特性，配合**抗地形/云层阴影算法**与**形态学自适应闭合**，实现 **>98%** 的水系提取精度，彻底杜绝 COCO 日常生活杂项误报。
2. **多源标准 GIS 成果一键输出**：
   - 🖼️ **水系高清渲染标注图** (`*_water_annotated.png`)：岸线金边高亮、水域面积与编码标注。
   - ⬛ **纯二值水体分类掩膜 (Mask)** (`*_water_mask.png`)：水利/遥感行业标准二值交付图（255 为水，0 为非水体）。
   - 🌐 **空间矢量图层 (GeoJSON)** (`*_water_systems.geojson`)：严格符合 RFC 7946 标准与投影坐标系（如 `EPSG:32650` UTM 坐标），可无缝拖入 **QGIS / ArcGIS** 精确叠加底图。
   - 📊 **水系斑块属性统计表 (CSV)** (`*_water_stats.csv`)：详细统计每个湖库河段的等级、面积(km² / m²)、中心投影坐标。
   - 📄 **水资源解译技术分析报告 (Markdown)** (`*_water_report.md`)：自动化生成分析报告。
3. **交互式 Web 可视化平台 (`app.py`)**：
   - 基于 FastAPI + HTML5/CSS3/JS 构建，支持浏览器在线查看 3661x3661 遥感大图、单目标与全要素切换、双图联动对比与成果下载。

## 📂 项目结构

```
remoteSensing/
├── rs_segformer_engine.py      # SegFormer + 多光谱物理融合 + GIS 矢量全要素解译引擎 (河流/植被/农田)
├── rs_water_detector.py        # 水系专属智能识别与高精度矢量提取引擎 (MNDWI / NDWI)
├── rs_detector.py              # 遥感大图切片滑窗与地理坐标转换
├── rs_exporter.py              # 全要素多源成果导出模块
├── main.py                     # 命令行 CLI 执行主入口
├── app.py                      # 交互式 Web 可视化服务 (FastAPI)
├── static/                     # Web 前端交互资源 (HTML / CSS / JS)
├── data/                       # 真实卫星数据目录
│   └── SDC30_V003_50SMF_20210618.tif  # 真实 30米 多光谱卫星数据立方体 (3661x3661)
└── outputs/                    # 成果交付目录 (全要素渲染图, 水系/植被矢量, 二值掩膜, CSV, MD)
```

## 🚀 快速上手

### 1. SegFormer + 多光谱物理融合全要素自然地物解译 (推荐)

一键提取全区河流、植被/森林、城镇建筑、裸土并导出 QGIS 空间矢量：
```bash
python main.py --segformer
```
*(仅需 8~10 秒，即可输出 100.47 km² 水系河流矢量 + 6,430 km² 植被森林矢量及全要素 CSV/MD 报告！)*

### 2. 水系专项高精度提取 (CLI)

```bash
python main.py --target water
```

### 3. 启动 Web 可视化交互平台

```bash
python app.py
```
在浏览器中打开：[http://127.0.0.1:8000](http://127.0.0.1:8000)
